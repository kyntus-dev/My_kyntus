Importer des employés (fichier RH)

Tout fichier est accepté (Excel, CSV, texte) : seules les colonnes utiles sont lues — Nom, Prénom, CIN, date de naissance, situation familiale, nombre d'enfants, adresse, e-mail personnel, téléphone —, les autres sont ignorées. Une colonne « Nom complet » est séparée automatiquement. Le fichier fait référence : un employé qui a déjà sa fiche (même CIN ou même nom) n'est pas recréé, sa fiche est vérifiée et mise à jour d'après le fichier — valeurs différentes remplacées, champs vides complétés, jamais vidés. Les cas douteux sont signalés sans rien modifier. Les nouvelles fiches sont créées sans mail interne — les adresses s'importent ensuite depuis Mails internes.
